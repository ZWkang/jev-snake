## Why

当前项目首页仍是 TanStack Start 示例模板，没有游戏或对局记录能力。首版目标是用持续移动的贪吃蛇测试快速模型的实时决策：服务端不等待 Agent 思考，游客无需登录即可观察当前对局、历史与回放；人机共玩属于后续阶段。

## What Changes

- 页面仅提供观战、历史对局与回放入口，游客无需注册或登录。首版不提供「自己玩」、接管、发起对局或键盘操控入口。
- 棋盘、蛇节、障碍和奖励使用同一整数格坐标与等比缩放；整页生图仅作风格参考，不再作为布局精度依据。
- 持久保存对局摘要和已发生的过程，刷新后可按对局参与者与结果查看历史；中断局保留已提交记录，明确完整性与保存失败。首版不展示尚不存在的人类玩家筛选项。
- 历史回放支持播放/暂停、0.5×/1×/2×/4×、拖动时间轴、逐步前后和关键事件跳转；回放不重新随机生成，也不改变原始结果。
- 对局明确区分控制者与观测者；观测者的键盘、离开页面和回放操作不能向原局发送转向、暂停、重开或调速。
- 新增 Hono + SQLite 对局服务端，作为对局状态、动作校验、历史和回放数据的权威来源。WebSocket 承载 Agent 动作、确认和游客实时更新；HTTP 承载受保护的对局创建及公开历史/回放查询。
- 对局按服务端固定节拍持续移动，未收到有效新方向时保持原方向。Agent 的转向绑定当前实际局面的下一次移动与局面摘要；迟到、非法及同 tick 冲突均返回明确结果，不等待模型、不补做过期动作。
- 开局配置 `tickIntervalMs`，默认 300ms（约 3.33 格/秒），本局固定；支持改变下一局配置来测试不同速度。记录观察位置、目标 tick、服务端收件时间、接纳/拒绝及实际生效位置，区分端到端反应耗时与模型自行报告的推理耗时。
- 每局生成随机固定障碍，空闲格随机生成苹果；吃苹果得分并增长，周期出现有时限的星星加分奖励。
- 使用奶油白背景、粗黑轮廓、实色硬阴影和高饱和撞色；蛇身采用多色分节、糖果高光、明确朝向的眼睛及吃到奖励的短促反馈。
- 游客可调整回放播放倍速；原始对局的速度只读展示，游客不能更改原局速度。最初的键盘游玩和实时调速需求随人机共玩后移，不列为首版验收项。
- 先交付页面静态效果图、奖励素材样稿与完整规划；素材由 ImageGen 生成。预留 Seedance 视频提示词，视频属于可选视觉扩展，不进入首版游戏运行依赖。

## Capabilities

### New Capabilities

- `snake-gameplay`: 持续移动、固定节拍、下一 tick 转向、碰撞、完成棋盘及游客操作隔离。
- `snake-board-rewards`: 随机障碍、合法出生位置、苹果增长与星星限时加分。
- `snake-presentation`: 新粗野主义页面、彩色蛇身、奖励素材、反馈动效与响应式可读性。
- `snake-match-history`: 对局摘要、持久保存、参与者/结果筛选、记录完整性与中断状态。
- `snake-match-replay`: 按原始记录还原局面、时间轴、步进、倍速与关键事件导航。
- `snake-spectating`: 观测者页面、控制权隔离、同步状态与事件查看。
- `snake-jev-runner`: Typesafe / OpenRouter 结构化 API、单个在途请求、当前步绑定和真实决策记录。
- `snake-server`: Hono 服务、WebSocket 控制/观测协议、HTTP 查询、SQLite 原子保存与断线恢复。

### Modified Capabilities

无。`openspec/specs/` 当前没有已有能力规格。

## Impact

- 后续实现主要涉及前端路由、`src/features/snake/` 展示/回放、新建 `server/` 承载 Hono 和 SQLite、`shared/snake/` 承载公开契约，`public/assets/snake/` 承载已验收素材。
- 复用当前 SolidJS、TanStack Solid Router/Start、TypeScript、Vite 与 Tailwind。原方案“无需持久化”的结论已失效；需要对局存储与回放读取能力。
- **已确认：首版游客纯查看，后续人机共玩；对局服务端使用 Hono + SQLite。** 当前按程序化玩家调用服务端接口组织能力，新增默认直连 Typesafe jev-1.13.0、支持显式 OpenRouter 对照的独立运行器，不内置自动寻路或代选策略。
- **推进模型已确认：服务器按固定节拍持续移动，用于测试快速模型。** 等待模型与控制连接断线不暂停对局；服务端进程中断的活动局保留最后已提交位置并记为中断，不补跑停机时段。
- 新增后端独立运行/构建脚本、SQLite schema 和迁移、API/数据契约测试及前后端连接配置；服务部署需要持久磁盘。本地 SQLite 对局服务作为独立常驻服务，当前前端 Vercel 配置不能视作该服务已经有部署环境。
- 当前仓库未配置测试脚本；后续需为状态转换、碰撞、生成器与时间逻辑建立针对性测试。发现 `biome.json` 使用旧配置结构，而 package.json 声明 Biome 2；实际兼容性在实现验证时显式检查，不能吞掉失败。
- 用户已授权进入实现；本次实现包括服务端、JEV 运行器、游客页面与验证。
