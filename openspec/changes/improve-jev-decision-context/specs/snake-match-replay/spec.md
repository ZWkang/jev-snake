## MODIFIED Requirements

### Requirement: 查看决策输入

回放 SHALL 提供独立的决策输入面板，显示当前位置最近一次已记录决策实际发送的请求正文、观察 seq、实际观察位置与目标 tick（旧预判记录保留原标注），并支持复制 JSON。正文来自保存的请求，不按当前棋盘重新生成；不得包含认证头或密钥。面板 SHALL 区分旧坐标 context 与 v3 动作摘要，展示保存的 context 版本及已有输入成本数据，说明几何计算来自程序、最终选择来自模型，静态连通性和概率不等于保证存活。旧记录缺少新诊断时 SHALL 显示未记录，不补算。

#### Scenario: 定位一条决策

- **WHEN** 用户跳转到带有请求正文的已接纳或被拒绝决策
- **THEN** 面板展示该次实际请求，随回放位置更新，并区分历史预判正文与新记录的实际观察位置

#### Scenario: 旧记录没有请求正文

- **WHEN** 当前决策属于尚未保存请求正文的旧记录
- **THEN** 明确提示未保存，不拼造或重新调用模型补全

#### Scenario: 新旧 context 来回切换

- **WHEN** 用户查看 v2 历史与 v3 新局
- **THEN** 各自正文及复制内容与原记录一致；v3 不要求存在已从请求中移除的完整蛇身和障碍坐标，棋盘仍按原事件显示

#### Scenario: 未识别的 context

- **WHEN** 已存历史正文携带显示端未支持的 context 版本
- **THEN** 明确标示不支持该版本的语义说明，保留可用的原始 JSON，不用最新算法重算或改写历史
